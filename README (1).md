# by-sou — سيرفر الموقع (Node.js + SQLite)

الموقع دلوقتي بيشتغل على سيرفر حقيقي، والمنتجات متخزنة في قاعدة بيانات (SQLite)
على جهازك. أي منتج تضيفيه من لوحة التحكم هيظهر لكل زائر يفتح الموقع.

## 1. تثبيت المتطلبات (مرة واحدة بس)

لازم يكون عندك Node.js متثبت على جهازك (نسخة 18 أو أحدث).
تحميل من هنا لو مش متثبت: https://nodejs.org

بعد كده، افتحي Terminal / Command Prompt جوه فولدر المشروع (`by-sou-server`) ونفذي:

```bash
npm install
```

الأمر ده هيحمّل المكتبات المطلوبة (Express, SQLite, Multer). محتاج اتصال إنترنت
أول مرة بس.

## 2. تشغيل السيرفر

```bash
npm start
```

هيظهرلك رسالة زي:

```
✅ سيرفر by-sou شغال على http://localhost:3000
```

افتحي المتصفح على `http://localhost:3000` عشان تشوفي الموقع، أو
`http://localhost:3000/admin.html` عشان تدخلي لوحة التحكم.

السيرفر لازم يفضل شغال (النافذة مفتوحة) عشان الموقع يشتغل. لو قفلتي النافذة،
شغّلي `npm start` تاني.

## 3. هيكل المشروع

```
by-sou-server/
├── server.js          ← كود السيرفر (Express + SQLite)
├── package.json
├── db/
│   └── bysou.db        ← قاعدة البيانات (بتتعمل أوتوماتيك أول تشغيل)
├── uploads/            ← صور المنتجات المرفوعة من لوحة التحكم
└── public/              ← ملفات الموقع نفسها
    ├── index.html
    ├── admin.html
    ├── style.css
    ├── admin.css
    ├── app.js
    ├── admin.js
    └── by-sou.jpg
```

## 4. لو حابة تنشري الموقع فعلياً على الإنترنت

دلوقتي الموقع شغال على جهازك بس (`localhost`). عشان يبقى متاح لأي حد على
الإنترنت، محتاجة تستضيفي المشروع على سيرفر حقيقي، زي:

- **Render** أو **Railway**: بيدعموا Node.js + قواعد بيانات، وفيهم خطة مجانية للمشاريع الصغيرة.
- أي VPS (زي DigitalOcean أو Hetzner) لو حابة تتحكمي بنفسك بالكامل.

في الحالتين، بترفعي نفس الكود (`by-sou-server` بالكامل) على الاستضافة،
وقاعدة البيانات (`db/bysou.db`) بتتعمل هناك تلقائي أول تشغيل. لو حابة، أقدر
أساعدك في خطوات النشر خطوة بخطوة لما تختاري الاستضافة.

## 5. نسخ احتياطي للمنتجات

كل بياناتك في ملف واحد: `db/bysou.db`. تقدري تاخدي نسخة احتياطية منه في أي وقت
بمجرد نسخ الملف ده في مكان تاني.
